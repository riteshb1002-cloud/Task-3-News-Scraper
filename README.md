# Task 3 - Web Scraper for News Headlines

## Objective

The objective of this project is to scrape top news headlines from a public news website using Python.

## Tools Used

- Python
- Requests
- BeautifulSoup

## Features

- Sends an HTTP GET request
- Fetches HTML content
- Parses HTML using BeautifulSoup
- Extracts news headlines
- Removes duplicate headlines
- Saves headlines into a text file

## Project Files

- `news_scraper.py` - Python web scraper
- `headlines.txt` - Scraped news headlines
- `requirements.txt` - Required Python packages
- `README.md` - Project documentation
